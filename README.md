# 🥗 FIT BOWL – Healthy Homemade Foods

**Healthy is Happy! ❤️**

Fit Bowl is a responsive website designed for a homemade healthy food business. It showcases a variety of traditional, nutritious, and delicious homemade snacks prepared with quality ingredients.

The website provides customers with an easy way to explore food products, select multiple items, and place orders directly through WhatsApp.

## 🌐 Live Preview

- **Project Repository:** [Fit Bowl – GitHub](https://github.com/chanduyadav103/Fit-bowl)
- **Local Website:** Run the project locally using the instructions below.

## ✨ Features

- **Responsive Design:** Works on desktop, tablet, and mobile devices.
- **Home Page:** Attractive landing page introducing Fit Bowl.
- **Product Gallery:** Displays different homemade food products with images.
- **WhatsApp Ordering:** Customers can order individual products directly through WhatsApp.
- **Multiple Product Selection:** Select multiple products and add them to a cart.
- **Cart Functionality:** View selected products before placing an order.
- **Customer Testimonials:** Displays customer feedback with navigation and automatic rotation.
- **About Us:** Information about Fit Bowl and its homemade food offerings.
- **Why Choose Fit Bowl:** Highlights freshness, quality, hygiene, and homemade preparation.
- **Google Maps Integration:** Displays the business location.
- **Mobile Navigation:** Responsive navigation menu for smaller screens.

## 🚀 How to Run the Project Locally

Follow these steps to run Fit Bowl on your computer.

**1. Clone the repository**

```bash
git clone https://github.com/chanduyadav103/Fit-bowl.git
```

**2. Navigate to the project directory**

```bash
cd Fit-bowl
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`). To create a production build, run `npm run build`.

## 📱 Ordering Process

1. Visit the Fit Bowl website.
2. Explore the available homemade food products.
3. Click **Order Now** for an individual product or select multiple products.
4. Add your selected products to the cart.
5. Click **Order on WhatsApp**.
6. Confirm your order directly with Fit Bowl.

## 🎯 Project Objective

The main objective of Fit Bowl is to establish an online presence for a homemade healthy food business and make it easier for customers to discover products and place orders.

This project focuses on delivering a simple, user-friendly, and mobile-responsive shopping experience without requiring a complicated checkout process.
